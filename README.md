# Return Risk Assessment

A Python-based risk assessment engine that evaluates return requests using rating, transaction value, and account age.

## Features

- Input validation
- Risk score calculation
- Approve, Manual Review, and Reject decisions
- Batch processing
- Custom error handling

## Risk Factors

- Customer rating
- Transaction value
- Account age

## Technologies Used

- Python 3
- Object-Oriented Programming
- Exception Handling
- Automated Testing
